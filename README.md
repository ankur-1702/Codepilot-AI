# CodePilot AI

CodePilot AI is an AI-powered code review application that helps developers analyze their code and receive suggestions, explanations, and improvements.

## Features

- AI-powered code review
- Code quality and improvement suggestions
- Code explanation
- Clean and simple interface
- React-based frontend
- Node.js and Express backend
- Google Gemini API integration

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### AI
- Google Gemini API
